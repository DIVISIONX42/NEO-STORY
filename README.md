# 🎄 Neon Stories


Celebrate the wonder of life in 2025 with the **Homeless Army**, a neo 3D web xperience built with **React Three Fiber (R3F)** . This project brings to life, the important truths of fiorst world country problems through glowing neon-themed scenes, immersive storytelling, and a creative visual journey.

## 🧑‍💻 Installation & Setup

1. **Clone the repository:**
   ```bash
   https://github.com/SahilK-027/neon-christmas.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd neon-christmas
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
5. Open [http://localhost:5172](http://localhost:3000) to view it in the browser.
